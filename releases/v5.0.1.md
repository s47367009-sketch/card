# کارت‌آرا پرو ۵.۰.۱ — اصلاح نصب و فعال‌سازی

## دریافت و نصب
فایل **cartara-pro-v5.0.1.zip** را از Assets دریافت کنید (نه Source code).
از پیشخوان وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه نصب کنید.
پیش‌نیاز: وردپرس ۵.۸+، PHP ۷.۴+ و ووکامرس فعال ۵.۰+.
برای بررسی امن رسیدها، PHP Fileinfo لازم است.
پیش از ارتقا از فایل‌ها و پایگاه داده پشتیبان بگیرید.

## اصلاحات
- جلوگیری از خطای بحرانی نبود کلاس WC_Payment_Gateway هنگام نبودن/غیرفعال بودن ووکامرس؛ نمایش پیام راهنما.
- اضافه شدن وابستگی WooCommerce در هدر افزونه برای وردپرس‌های جدید.
- اصلاح SQL ساخت جدول‌ها برای سازگاری با dbDelta و کنترل شکست ساخت جدول.
- کنترل خطاهای دسترسی پوشه رسیدها و بازسازی فایل‌های محافظ مفقودشده.
- حذف کارت‌های بانکی ساختگی از نصب جدید؛ کارت‌های موجود و تنظیمات کاربر حذف نمی‌شوند.
- انتقال بارگذاری ترجمه به init و تعریف صریح ویژگی instructions برای PHP جدید.
- اصلاح بررسی کلاس HPOS و حذف آدرس آیکون ناموجود.
- کنترل آپلود ناقص و نبود Fileinfo با پیام خطا به‌جای خطای بحرانی.
- حذف اعلام نادرست پشتیبانی Checkout Blocks؛ فعلاً از تسویه‌حساب کلاسیک ووکامرس استفاده کنید.

## پس از نصب
کارت بانکی واقعی خود را در تنظیمات اضافه کنید. اگر نسخه ۵.۰.۰ را قبلاً نصب کرده‌اید، کارت‌های نمونه را در پنل بررسی و حذف/غیرفعال کنید. سپس درگاه را در تنظیمات پرداخت ووکامرس فعال و یک سفارش آزمایشی ثبت کنید.

## بررسی انجام‌شده
تمام فایل‌های PHP با PHP 8.5.10 lint شده‌اند. تست‌های ایزوله با شبیه‌ساز API وردپرس، نبود/قدیمی بودن/حضور ووکامرس، فعال‌سازی تکراری، حفظ تنظیمات، ترمیم پوشه و شکست پایگاه داده/آپلود را پوشش می‌دهند. ساختار و صحت ZIP بررسی شده است.
این تست‌ها جایگزین آزمایش عملی روی وردپرس، ووکامرس و MySQL واقعی یا تست کامل پرداخت نیستند؛ چنین محیطی در این اجرا در دسترس نبود. سازگاری همه نسخه‌های اعلام‌شده به‌صورت عملی تأیید نشده است.

این ریلیز فقط شامل افزونه وردپرس است و APK جدید منتشر نمی‌کند.
